# PokéVault – Pokémon TCG set tracker

A dark-purple, no-build static website for tracking Pokémon card master sets. Open the site, tap the cards you
own and they light up in full colour; everything else stays dimmed.

## What's in it

**Card catalogues**
- **English:** 201 sets (21,000+ cards, 40,000+ printings), Base Set (1999) to today, including Black Star promos,
  trainer kits, McDonald's and special sets. TCG Pocket (digital) is left out.
- **Japanese, Chinese (Traditional), Thai and Indonesian** catalogues, each with its own sets. Names appear as printed,
  with the English Pokémon name underneath, so searching "Charizard" finds リザードンex.

**Master sets**, in set order, with every printing of each card:
- Normal / holo / reverse holo / 1st Edition / Shadowless; holo rares are labelled "Normal (Holo)".
- Special reverses: Poké Ball, Master Ball, Energy Symbol, Dusk / Love / Friend / Quick Ball, Team Rocket, Cosmos,
  Cracked Ice. Japanese master sets include Mirror and pattern reverses.
- Jumbo (oversized) cards are kept out of the master sets, in their own **Jumbo Cards** set.
- Stamped and exclusive printings: Play! Pokémon Prize Pack (every variation), League / Championship / Staff,
  Prerelease, Pokémon Center, Professor Program, deck and blister exclusives, calendars, Trick or Trade, Battle Academy.
  Each has its own photo and price. Toggle them with **Stamped: Show / Hide**.

**Tracking and value**
- Portfolio page: total value (raw and graded shown separately), most valuable cards, set progress, value by era.
- Sort by value inside a set, or across every set in the Card Explorer.
- Prices in **£ (default), $ or €**. Pounds use Cardmarket at today's exchange rate, dollars use TCGplayer. Set pages and
  the portfolio load live prices when opened (cached for 12 hours).
- Graded and other-language copies: open a card's **i** details to add a PSA / CGC / BGS… copy and/or a German,
  Japanese… copy, each with its own value.
- Graded market prices (PSA 10, PSA 9, CGC 9.5…) are filled in daily once an API key is set up (see below).

**Views**
- Grid or flip-through binder pages (4-, 9-, 12- or 16-pocket, two-page spreads, page 1 on its own like a real binder).
- **My binders:** build your own binders from any cards, for example everything with Jigglypuff in it.
- Search finds Pokémon that appear in a card's artwork. Searching "Snivy" finds Fates Collide Jigglypuff 65/124.
- Multi-select to add or remove many cards at once.

**Your data:** the collection and binders are saved in your browser. In **Settings** you can export or import a backup,
or sync across devices with a private GitHub gist. Each person uses their own GitHub token or collection name.

## Running it

It's plain HTML/CSS/JS, so any static host works:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

GitHub Pages: *Settings → Pages → Deploy from a branch*, then pick the branch and the root folder.

## Card data

`data/` is generated by scripts in `scripts/`:

| Script | What it does |
| --- | --- |
| `build-data.mjs [--lang=xx] [setId …]` | Builds a catalogue from [TCGdex](https://tcgdex.dev) (`en`, `ja`, `zh-tw`, `th`, `id`) and then runs the steps below |
| `fill-gaps.mjs` | Adds cards TCGdex is missing (e.g. Sun & Moon "a" prints, 30th Celebration Mew B/G/R) from [pokemontcg.io](https://pokemontcg.io) |
| `add-stamps.mjs [--lang=ja]` | From TCGplayer's catalogue ([tcgcsv.com](https://tcgcsv.com)): stamped / exclusive / Prize Pack printings, plus missing reverse holos, 1st Editions and pattern photos; for Japanese, missing Mirror and pattern reverses |
| `fill-images.mjs [--lang=xx]` | Fills missing pictures from pokemontcg.io / TCGplayer, or the Japanese print for other Asian languages (marked "JP image") |
| `build_cameos.py` | Builds `data/cameos.json` (Pokémon in the artwork) from [RotomAmiti's Cameo Pokémon Card Database](https://docs.google.com/spreadsheets/d/18nIkOgqQrHZTz0TrH_gL1e1nL1RcHiCmPF5finAjToY) |
| `fetch-graded.mjs` | Fetches graded market prices into `data/graded.json` (needs `PPT_API_KEY`) |

Each step keeps a copy of its last good result (`data/extra-cards.json`, `data/stamp-variants.json`,
`data/ja/printings-cache.json`, `data/image-fill.json`), so an outage at one source never removes cards.

GitHub Actions (main branch only):
- **Refresh card data & prices:** every Monday. Rebuilds every catalogue and the cameo list.
- **Fetch graded prices:** daily, about 45 cards a day, most valuable first.
  1. Get a free key at https://www.pokemonpricetracker.com/api-keys.
  2. Add it as a repository secret called `PPT_API_KEY` (*Settings → Secrets and variables → Actions*).
  3. Run the workflow once.

There is no free price source for each card language, so other-language copies of English cards use the value you
enter, or the English price.
